1. The "Fresh Machine" Crash (Missing Git Identity)

If a user runs your tool on a computer that has never used Git before, the ensure_branch_exists function will fail. Git refuses to create the initial commit unless user.name and user.email are configured globally or locally.

The Fix: Temporarily inject a dummy identity for the initial commit.

Python

 

def ensure_branch_exists(path, branch="main"):
    if not has_commits(path):
        git_run(["add", "-A"], cwd=path, capture_output=True)
        # Inject config directly into the commit command for fresh environments
        cmd = [
            "-c", "user.name='Auto Builder'", 
            "-c", "user.email='auto@builder.local'", 
            "commit", "--allow-empty", "-m", "initial"
        ]
        r = git_run(cmd, cwd=path, capture_output=True, text=True)
        if r.returncode != 0 and "nothing to commit" not in r.stdout and "nothing to commit" not in r.stderr:
            git_run(cmd, cwd=path, capture_output=True)

2. Unicode Decode Errors on Windows

In is_valid_git_repo, ensure_on_branch, and other functions, you are passing text=True to subprocess.run. On Windows, Python defaults to the system's local encoding (like cp1252), not UTF-8. If a user's system language is set to something non-English, Git will output localized error messages. Python will hit an unknown character, throw a UnicodeDecodeError, and crash the entire .exe.

The Fix: Force UTF-8 and replace bad characters in your git_run wrapper.

Python

 

def git_run(args, cwd=None, **kwargs):
    try:
        # If the caller wants text/string output, enforce safe UTF-8 decoding
        if kwargs.get('text') or kwargs.get('universal_newlines'):
            kwargs['encoding'] = 'utf-8'
            kwargs['errors'] = 'replace' # Prevents crashes on weird characters
            
        return subprocess.run([get_git_path()] + args, cwd=cwd, **kwargs)
    except FileNotFoundError:
        return _dummy_result()

3. Missing Push Rejections (Large Files & Protected Branches)

Your detect_push_error function looks for authentication and network errors, but misses two very common GitHub blocks:

  • Large Files: GitHub rejects files over 100MB. If a user accidentally stages a massive .zip or .exe, the push will fail, but your script won't catch the specific reason.
  • Protected Branches: If they are pushing to a repository where main requires a pull request, Git returns a specific decline message.

The Fix: Add these checks to detect_push_error.

Python

 

def detect_push_error(stderr):
    if not stderr:
        return None
    if "Authentication failed" in stderr or "403" in stderr or "401" in stderr:
        return AuthFailed("Authentication failed — check your GitHub token")
    if "GH001" in stderr or "large files" in stderr:
        return PushRejected("GitHub rejected the push because a file exceeds the 100MB limit.")
    if "protected branch" in stderr or "hook declined" in stderr:
        return PushRejected("Push rejected — branch is protected.")
    if "Could not read from remote" in stderr or "resolve host" in stderr or "Connection refused" in stderr or "Network is unreachable" in stderr:
        return NetworkError("Network error — check your internet connection")
    if "rejected" in stderr and "fetch first" in stderr:
        return PushRejected("Remote has commits you don't have locally")
    if "rejected" in stderr or "failed to push" in stderr:
        return PushRejected("Push was rejected")
    return None

4. _extract_github_user Index Out of Range Bug

If the user passes exactly https://github.com/username (without a trailing slash or repository name), your extraction logic fails silently.

Python

 

# CURRENT LOGIC:
if '/' in after:
    return after.split('/')[0]
return "" # Returns empty string if no slash exists!

The Fix: Let it return the remainder of the string if there are no slashes.

Python

 

def _extract_github_user(url):
    url = url.strip()
    if 'github.com/' in url:
        after = url.split('github.com/', 1)[1]
        return after.split('/')[0] if '/' in after else after
    if 'github.com:' in url:
        after = url.split('github.com:', 1)[1]
        return after.split('/')[0] if '/' in after else after
    return ""
